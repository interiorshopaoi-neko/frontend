## 判断基準

新機能の優先度を決めるときは以下を確認：

1. **職人の仕事が増えるか？** → S/A優先
2. **依頼者のハードルが下がるか？** → S/A優先
3. **運営コストが下がるか？** → A優先
4. **「動くデモUI」で先に確認できるか？** → 先に実装して判断
5. **DB設計・法律・決済が絡むか？** → 慎重にB以降
