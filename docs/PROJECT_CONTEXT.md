## サービス概要

**PRO MATCH** は、内装工事（壁紙・床CF）の依頼者と職人をつなぐ **動画ファーストのマッチングプラットフォーム**。

- 依頼者がショート動画・写真を送る → 職人が概算金額を提示 → 成約 → 連絡先開示 → 工事
- 工事代金は依頼者と職人が**直接**やり取りする
- PRO MATCHはマッチングの場を提供するだけ

---

## ターゲット

| ユーザー | 説明 |
|---|---|
| 依頼者（お客様） | 壁紙・床の張替えを依頼したい個人・法人 |
| 職人（PRO） | 内装工事を請け負う個人職人・小規模業者 |
| 運営者 | 管理ダッシュボード（`/admin/dashboard`）から状況確認 |

---

## 収益モデル（重要）

### 通常案件
- **お客様：完全無料**（見積もり・相談・職人選びまで）
- **職人：成約時のみ手数料**（概算金額ベースで確定）
- 手数料は成約時点で確定。工事後に金額が増減しても**原則再計算しない**
- PRO MATCHは工事代金を**預からない**
- 工事代金は依頼者と職人が**直接**やり取りする

```
手数料テーブル（職人側のみ）:
〜 ¥30,000      → ¥500
〜 ¥80,000      → ¥1,500
〜 ¥150,000     → ¥3,000
  ¥150,001〜    → ¥5,000
```

### 応援マッチング（職人同士）
- 現在は**無料**
- 正式版では募集側・参加側それぞれ **¥300** を予定
- 今は決済実装しない。UI表示のみ

## 世界観・UX方針

- **「職人OS」構想**：`/tools` を職人の日常業務ツール（利益管理・見積・現場メモ）の起点にする
- **動画ファースト**：テキスト入力より動画・写真で状況を伝える設計を優先
- **成約前は個人情報を開示しない**：住所・電話番号は成約後のみ開示
- **1画面1目的**：情報を詰め込みすぎない

## ナビゲーション方針

- **BottomNav は4タブ固定**：案件 / 管理 / 応援 / マイページ
- **BottomNavにタブを追加しない**（UX優先）
- 新機能は既存ページへのカードリンクや `/tools` に収める
- `/tools` は直接URLアクセス可。BottomNavには出さない

---

## 開発文化

- **最小差分（Minimum Diff）文化**：既存UIを壊さない・変更範囲を絞る
- **MVP優先**：完璧より動くものを先に
- **TypeScriptエラーゼロ必須**：`npx tsc --noEmit` を毎回確認
- **Supabase構造変更は原則しない**：既存テーブルを使い回す
- **デモfallback OK**：DB未実装ならローカルstateやconsole.logで代替

---

## 禁止事項（AIへの注意）

- お客様側に手数料金額（¥500〜¥5,000・¥300等）を表示しない
- BottomNavのタブを増やさない
- 工事代金のエスクロー・一部預かり設計にしない
- Stripe等の決済は未実装（実装依頼がない限り追加しない）
- 複雑なグラフライブラリを入れない
